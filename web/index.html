F2A-64 · 密钥与二维码生成器

给你的网站用户生成「密钥 + 二维码」。纯前端运行，密钥不出浏览器，可离线使用。
位数建议：6 位算法用 16 字符密钥；64 位算法用 64 字符密钥。

两种算法对照

项目标准 6 位 TOTPF2A-64
哈希算法HMAC-SHA1HMAC-SHA512
时间窗口30 秒60 秒
输出长度6 位数字64 位字符（0-9 A-Z）
组合空间10^636^64 ≈ 10^99
兼容性谷歌/微软验证器F2A-64 App
关键：两种算法共用同一把 Base32 密钥 —— 所以用户只存一条密钥，既能给老系统出 6 位，也能给新系统出 64 位。

服务端怎么校验（Python）

import hmac, hashlib, struct, time, base64 TABLE = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ" def code64(secret_b32: str, step: int = 60) -> str: """F2A-64：64 位动态码""" key = base64.b32decode(secret_b32.upper() + "=" * (-len(secret_b32) % 8)) counter = int(time.time()) // step h = hmac.new(key, struct.pack(">Q", counter), hashlib.sha512).digest() # 64 字节 return "".join(TABLE[b % 36] for b in h) # 64 字符 def verify(secret_b32: str, user_input: str, step: int = 60, window: int = 1) -> bool: """允许前后各一个窗口（容忍时钟偏差）""" now = int(time.time()) // step for off in range(-window, window + 1): key = base64.b32decode(secret_b32.upper() + "=" * (-len(secret_b32) % 8)) h = hmac.new(key, struct.pack(">Q", now + off), hashlib.sha512).digest() if "".join(TABLE[b % 36] for b in h) == user_input.strip().upper(): return True return False
6 位 TOTP 用标准的 pyotp.TOTP(secret).verify(code) 就行。

三种接入方式

方式怎么做
推荐 扫码把生成的二维码显示给用户，用户用 F2A-64 App 扫一下就行
手动 输密钥把 ② 里的密钥给用户，让他在 App 里「添加密钥」粘贴
