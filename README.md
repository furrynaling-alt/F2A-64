# F2A-64 · 双算法验证器

> 一个 App，同时支持 **标准 6 位 TOTP** 和 **64 位 F2A 动态码**。
> 山寨验证器只给你 6 位；F2A-64 给你 64 位更强的一次性口令，还保持 6 位兼容。

对标微软/谷歌验证器，但多了两样东西：
1. **64 位时间算法**（HMAC-SHA512 → 36 进制，60 秒一变）
2. **防窥屏开关**（系统级禁止截图/录屏）

---

## 一、两种算法是怎么算的

### ① 标准 TOTP（6 位数字，30 秒一变）

```
counter = floor(unixTime / 30)                    ← 每 30 秒计数器 +1
hmac    = HMAC-SHA1(secret, counter)              ← 20 字节
offset  = hmac[19] & 0x0F                         ← 动态截断起点
bin     = ((hmac[offset]   & 0x7F) << 24)
        | ((hmac[offset+1] & 0xFF) << 16)
        | ((hmac[offset+2] & 0xFF) << 8)
        |  (hmac[offset+3] & 0xFF)
code    = bin mod 10^6                            ← 补零成 6 位
```

这是 RFC 6238 的标准实现，跟谷歌验证器完全兼容。

### ② F2A-64（64 位字符，60 秒一变）

```
counter = floor(unixTime / 60)                    ← 窗口 60 秒（不是 30）
hmac    = HMAC-SHA512(secret, counter)            ← 正好 64 字节
code    = 逐字节映射到 36 进制表  "0-9A-Z"
          code[i] = TABLE[ hmac[i] mod 36 ]       ← 每个字节 → 1 个字符
结果    = 正好 64 个字符
```

**为什么是 36 进制？**
0-9 + A-Z 共 36 个可读符号。把每个字节（0~255）对 36 取模，得到一个可读字符。
64 字节 → 64 个字符，一位不多一位不少。

**为什么更安全？**
- SHA512 输出 512 位（SHA1 只有 160 位）
- 60 秒窗口（比 30 秒少一半的猜测机会）
- 64 位字符空间 = 36^64 ≈ 10^99 种组合

**关键设计：两种算法共用同一把 Base32 密钥。**
所以同一把密钥，喂给只认 6 位的老系统能用；喂给支持 64 位的新系统，就能拿到 64 位动态码。

### 两种算法的对照

| | 标准 TOTP | F2A-64 |
|---|---|---|
| 哈希 | HMAC-SHA1 | **HMAC-SHA512** |
| 窗口 | 30 秒 | **60 秒** |
| 输出 | 6 位数字 | **64 位字符（0-9 A-Z）** |
| 组合空间 | 10^6 | **36^64 ≈ 10^99** |
| 兼容 | 谷歌/微软验证器 | 本 App 自有的新算法 |

## 二、功能

- ✅ 添加/删除多条密钥，各自选 6 位或 64 位
- ✅ 实时刷新（6 位 30 秒一变，64 位 60 秒一变）
- ✅ 一键复制验证码
- ✅ **导入 / 导出**（JSON 文本，自己保管就是备份）
- ✅ **防窥屏开关**（开启后系统禁止截图/录屏，`FLAG_SECURE`）
- ✅ **无网络权限** —— 密钥只存在本机，绝不上传
- ✅ 无广告、无账号、无统计

---

## 三、实现要点（源码结构）

单个文件 `MainActivity.kt`，约 450 行，零第三方依赖（除 zxing 备用）。

```
b32(s)              Base32 解码（RFC 4648，容忍空格/连字符/小写）
counterBytes(step)  把 (unixTime/step) 编成 8 字节大端
totp(secret, step)  ① 标准 6 位
code64(secret, step)② F2A-64（HMAC-SHA512 → 36 进制）
codeOf(条目)        按条目的 t 字段分发到上面两个
```

**自定义窗口长度**：每条密钥可以单独设置 `step`（默认 6 位用 30 秒、64 位用 60 秒）。

## 四、构建

```bash
# 需要 JDK 17 + Android SDK
keytool -genkeypair -keystore f2a64.keystore -alias f2a64 \
        -keyalg RSA -keysize 2048 -validity 10000
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```
